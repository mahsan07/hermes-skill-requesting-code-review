# Hermes Skill: Requesting Code Review

A small, shareable skill package extracted from the Hermes catalog.

## What it does

Run a pre-commit quality and security pass and prepare a focused review request.

## Example

> Review the current diff, run the project checks, fix only obvious issues, and draft a reviewer handoff.
